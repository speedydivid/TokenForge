# Contributing to TokenForge

Thank you for your interest in TokenForge.

## Project Structure

TokenForge is organized into separate components and supporting resources. Each component may serve a different purpose within the project.

## Guidelines

- Keep files organized by purpose.
- Use descriptive filenames.
- Document important changes.
- Avoid committing credentials, API keys, or other sensitive information.
- Test changes before submitting them.

## Reporting Issues

When reporting an issue, include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected and actual behavior.
- Relevant error messages or logs.

## Contributions

Contributions should be focused, documented, and consistent with the project's existing structure.

Thank you for helping improve TokenForge.
