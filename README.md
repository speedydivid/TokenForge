## ✨ Features

- **Context Compression** — reduce unnecessary tool output by up to 98% in supported workflows.
- **Persistent Memory** — store and retrieve session knowledge using SQLite and FTS5 full-text search.
- **Smart Tool Routing** — manage tool interactions across 17 supported platforms.
- **MCP Integration** — connect AI coding agents through the Model Context Protocol.
- **Automatic Hooks** — optimize tool output and context flow directly within supported workflows.
- **Session Continuity** — retain useful context between sessions without repeatedly explaining the same things.
- **Token Efficiency** — reduce redundant context and keep coding sessions focused.
- **Multi-Agent Support** — integrate with popular AI-powered development environments.

## ⚙️ How It Works

1. Intercepts supported tool interactions through hooks and MCP integrations.
2. Filters or compresses excessive tool output before it reaches the agent.
3. Stores useful session information in a local SQLite database.
4. Retrieves relevant memories through FTS5 search.
5. Routes supported interactions through a consistent optimization layer.
